# 鷲の目紀行（イーグル隊長の空中散歩）

イーグル隊長の背中に乗って、テーマ別（世界遺産・日本の世界遺産・日本のお城など）のスポットを空から巡るWebアプリです。

## ファイル構成

```
eagle-captain/
├── index.html      … 画面（テーマ切替・3D地図・選定パネル・会員モーダル・バージョン表示）
├── style.css       … 計器盤×フライトログ風デザイン（スマホ対応）
├── config.js       … GAS URL・バージョン等の設定
├── auth.js         … API通信・会員登録／ログイン／強制PW変更／再発行／目玉アイコン
├── app.js          … CesiumJS制御・フライト演出・3つの選定モード・TTS・Gemini取り込み
├── README.md
└── gas/
    └── Code.gs     … GASバックエンド（認証・シートCRUD・Geminiプロキシ・TTSキャッシュ）
```

## 構成のポイント

- 地図は CesiumJS。トークン無しでも Esri 航空写真で動作し、`CESIUM_ION_TOKEN` を入れると3D地形＋3D建物になります。
- Gemini APIキーはフロントに置かず、GASのスクリプトプロパティで管理します（GitHub Pagesはソースが公開されるため）。
- 隊長ボイスは Gemini TTS → 失敗時ブラウザ音声（低音男性）の順で再生。同じセリフは Drive にキャッシュし、API消費を抑えます。
- 豆知識と写真ギャラリーは Wikipedia（日本語版）から自動取得します。
- スプレッドシートには仕様の3シートに加え、ログイン状態を管理する `Sessions` シートを追加しています。

---

## 1. スプレッドシートの作成

1. Googleドライブで新しいスプレッドシートを作成（名前例：`eagle_captain_db`）。
2. メニュー「拡張機能」→「Apps Script」を開く。
3. 既存の `コード.gs` の中身を削除し、`gas/Code.gs` の内容をすべて貼り付けて保存。
4. 関数選択で `setup` を選び「実行」。権限承認（スプレッドシート・Gmail・Drive・外部通信）を許可。
   - `Users` / `Themes` / `Spots` / `Sessions` の4シートが作成され、3テーマ・20スポットのサンプルが入ります。

## 2. スクリプトプロパティ

Apps Script の「プロジェクトの設定」→「スクリプト プロパティ」に追加：

| プロパティ | 必須 | 内容 |
|---|---|---|
| `GEMINI_API_KEY` | ○ | Google AI Studio で発行したキー |
| `GEMINI_MODEL` | | 既定 `gemini-2.5-flash` |
| `TTS_MODEL` | | 既定 `gemini-2.5-flash-preview-tts`（新しいTTSモデルを使う場合はここを変更） |
| `TTS_VOICE` | | 既定 `Orus`。`Charon` `Fenrir` `Algenib` なども試せます |
| `ADMIN_EMAILS` | 推奨 | 管理者のメールアドレス（複数はカンマ区切り）。全カテゴリの名前変更・削除、全スポットの削除ができます |

設定後、エディタで `testGemini` と `testTts` を実行し、ログにセリフと音声データ長が出れば準備完了です。

## 3. GASのデプロイ

1. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」。
2. 次のユーザーとして実行：**自分**
3. アクセスできるユーザー：**全員**
4. デプロイして表示された `https://script.google.com/macros/s/……/exec` をコピー。
5. コードを修正したときは「デプロイを管理」→ 鉛筆アイコン →「新バージョン」で更新（URLは変わりません）。

## 3.5 Google フォトリアル3D（空から見た立体の街並み）

1. Google Cloud コンソールで、いつものプロジェクトの「APIとサービス」→「ライブラリ」から **Map Tiles API** を有効化。
2. 「認証情報」→ APIキーを作成（または既存キーを編集）。
   - アプリケーションの制限：HTTPリファラー → `https://kenken6291.github.io/*`
   - APIの制限：Map Tiles API
3. `config.js` の `GOOGLE_MAPS_API_KEY` にキーを貼り付け。
4. 利用量に応じた課金があるため、「割り当て」で1日の上限を設定しておくと安心です。

キーが空、または読み込みに失敗した場合は、平面の航空写真で表示されます。

## 4. GitHub Pages への配置

1. `config.js` の `GAS_API_URL` に上記URLを貼り付け、`VERSION` を必要に応じて更新。
2. `gas/` フォルダ以外（index.html / style.css / config.js / auth.js / app.js）をリポジトリへpush。
3. リポジトリの Settings → Pages で `main` ブランチ / root を公開。
4. `https://kenken6291.github.io/<リポジトリ名>/` を開いて確認。

## 空撮映像（Google Earth Studio）の登録

`Spots` シートの `video_url` 列に URL を入れると、到着時に映像が重なって再生されます。

- Google Drive：ファイルを「リンクを知っている全員」に共有し、`https://drive.google.com/file/d/ファイルID/view` 形式のURLを貼る
- YouTube：通常の動画URLでOK（ミュート自動再生・ループ）
- MP4 / WebM を直接置く場合：GitHub Pages内に置いて相対パスでも可

## カテゴリ・スポット管理（⚙️ボタン）

- カテゴリの追加・名前とアイコンの変更・削除（中のスポットもまとめて削除）
- スポットの一括削除：「取り込み単位」で絞り込むと、1回の取り込みで入れたリストをまとめて選んで削除できます
- 権限：管理者（`ADMIN_EMAILS`）はすべて、一般会員は自分が作ったカテゴリ・自分が取り込んだスポットのみ
- 初期データや v1.3.0 より前に取り込んだスポットは作成者の記録がないため、管理者だけが削除できます

## 行ったところ（📒ボタン）

- スポットのカードで「行ったところにチェック」→ ワンタップで記録（日付は今日）。地図のピンが緑＋「✔」になります
- 「写真・メモを追加／記録を編集」で、行った日・思い出メモ（500文字）・写真（6枚まで）を登録・修正
- 写真はブラウザ側で長辺1600px・JPEGに縮小してから送信（1枚あたり約200〜500KB）。Googleドライブの `eagle_captain_photos` フォルダに保存されます
- 写真を外す・チェックを外すと、ドライブの写真もゴミ箱へ移動します
- 📒「行ったところリスト」：カテゴリ別の達成率、並び替え、写真の拡大表示、もう一度飛ぶ・編集・削除
- 記録は `Visits` シートに会員ごとに保存されます（初回利用時に自動作成）
- 写真は「リンクを知っている人が閲覧可」で共有されます（URLは推測できない長い文字列です）

## 補足

- AIが作ったスポットの緯度経度は誤ることがあります。取り込み画面の座標リンク（Googleマップ）で確認してから保存してください。
- 期限切れセッションの掃除は、`cleanupSessions` を時間主導トリガー（1日1回）に設定すると自動化できます。
